# ResearchStat AI Architecture

The editable source is [`ResearchStat-AI-architecture.drawio`](ResearchStat-AI-architecture.drawio).

It contains two pages:

- **System Architecture**: implemented V1 layers, local privacy boundary, Python/R execution, validation, audit, figures, and integration exits.
- **Analysis Workflow**: the end-to-end path from a natural-language request to a reproducible analysis package.

The diagram is protocol-first: AI recommends a registered protocol, a human reviews it, engines calculate, validation challenges the result, and audit records the complete context.

本架构图使用标准 draw.io XML，可直接在 diagrams.net 中打开和编辑。
