# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Report privately
through the repository owner or a private advisory so the issue can be
addressed before disclosure.

## Local Data

ResearchStat AI defaults to local processing. Do not upload sensitive research
data to external services unless you explicitly configure an approved external
LLM backend and have obtained consent.
